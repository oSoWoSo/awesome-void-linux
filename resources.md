# Void Linux resources

Curated list of official and community Void Linux resources.

## Official

- Void Linux homepage - https://voidlinux.org
- The Void Linux Handbook - https://docs.voidlinux.org
- Void Linux manpages - https://man.voidlinux.org
- InfraDocs (Void systems management) - https://infradocs.voidlinux.org
- GitHub organization - https://github.com/void-linux
- void-packages (package templates) - https://github.com/void-linux/void-packages
- void-docs (handbook sources) - https://github.com/void-linux/void-docs
- void-mklive (live image builder) - https://github.com/void-linux/void-mklive
- void-installer - https://github.com/void-linux/void-installer

- Reddit r/voidlinux - https://reddit.com/r/voidlinux
- Void Linux Wiki - https://wiki.voidlinux.org
- oSoWoSo community - https://osowoso.org
